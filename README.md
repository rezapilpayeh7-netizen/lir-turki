# 💱 ربات نرخ لحظه‌ای ارز

ربات تلگرام برای دریافت و ارسال خودکار نرخ‌های ارز به کانال با قابلیت مدیریت کامل، تولید تصویر و پنل ادمین.

---

## ✨ امکانات

- دریافت نرخ از API و ارسال خودکار به کانال
- پشتیبانی از ۸ ارز (دلار، یورو، پوند، لیر، درهم، تتر، یوان، دلار کانادا)
- تولید تصویر با قالب اختصاصی و آیکون‌ها
- پنل مدیریت کامل با کیبورد
- تنظیم نرخ دستی (دلار، درهم، تتر)
- مدیریت نمایش ارزها و وضعیت فروش
- تغییر زمان‌بندی و کانال
- خاموش/روشن کردن ربات
- تاریخ شمسی و آیکون تغییرات (📈📉➖)
- محدودیت دسترسی ادمین

---

## 🛠️ تکنولوژی‌ها

- Python 3.10+
- python-telegram-bot
- Pillow (تولید تصویر)
- APScheduler (زمان‌بندی)
- jdatetime (تاریخ شمسی)

---

## 🚀 نصب و اجرا

### ۱. کلون کنید

```bash
git clone https://github.com/rezapilpayeh7-netizen/lir-turki
cd lir-turki
```

### ۲. محیط مجازی

```bash
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```

### ۳. نصب کتابخانه‌ها

```bash
pip install -r requirements.txt
```

### ۴. تنظیم فایل محیطی

فایل `.env.example` را به `.env` کپی کنید و مقادیر واقعی خود را جایگزین کنید:

```bash
cp .env.example .env
```

سپس `.env` را ویرایش کنید:

```
BOT_TOKEN=your_bot_token_here
API_KEY=your_api_key_here
CHANNEL_ID=@your_channel
ADMIN_ID=your_admin_id
```

> ⚠️ هرگز فایل `.env` را در گیت‌هاب آپلود نکنید.

### ۵. اجرا

```bash
python3 main.py
```
